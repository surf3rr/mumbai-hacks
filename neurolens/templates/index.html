NeuroLens

Real-time Autism Behavioral Screening

A computer vision-based tool for preliminary behavioral analysis

How It Works

  • This tool analyzes behavioral markers through your webcam during a 2-minute session
  • It tracks eye contact, head movement, facial expressions, and attention patterns
  • Results are computed using validated behavioral markers associated with autism spectrum traits
  • Important: This is not a diagnostic tool but a screening aid for early identification
